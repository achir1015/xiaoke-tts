## 下載安裝

| 系統 | 檔案 |
|---|---|
| Windows 10／11（64 位元） | `XiaokeTTS-Setup-版本.exe`（不需要系統管理員權限，可自選安裝資料夾） |
| Mac（Apple 晶片 M1～M4） | `XiaokeTTS-mac-AppleSilicon-版本.dmg` |
| Mac（Intel） | `XiaokeTTS-mac-Intel-版本.dmg` |
| Android 8 以上手機／平板 | `XiaokeTTS-Android-版本.apk`（下載後點開安裝，需允許「安裝不明的應用程式」） |
| iPhone、iPad、任何瀏覽器 | 線上版 https://achir1015.github.io/xiaoke-tts/（可「加入主畫面」） |

打開 App 就能用：語音引擎自動連線，不用安裝其他程式或開命令列；關掉視窗就完全結束。
產生的 MP3 自動存到「音樂\小柯語音」（Android：音樂/小柯語音）。
第一次使用請到「設定」貼上免費的 Hugging Face 權杖（沒登入每天只能產生幾次）。
Mac 版沒有 Apple 簽章：第一次請在「應用程式」裡對 App 按右鍵 →「打開」。詳細說明在 .dmg 裡的「第一次開啟請看這裡.txt」。
已安裝的桌面版與 Android 版會自動提示新版本，按「立即更新」即可。
